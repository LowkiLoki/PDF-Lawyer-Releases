# YourApp Releases

Official download and update channel for Lawyer PDF.

> **This repository contains release binaries only.** It does not contain the application's source code. Issues and discussions here are limited to installation, updates, and release-related questions.

---

## Download

Get the latest installer from the [**Releases page**](../../releases/latest).

| Platform               | File                   | Notes            |
| ---------------------- | ---------------------- | ---------------- |
| Windows 10/11 (64-bit) | `PDF-Lawyer-Setup.exe` | Wizard installer |

## Installation

1. Download the latest installer for your platform from the Releases page.
2. Run the installer and follow the setup wizard (choose install location, shortcuts, etc.).
3. Launch PDF Lawyer from the Start Menu or desktop shortcut.

> **Windows SmartScreen:** if you see an "unrecognized app" warning, click **More info → Run anyway**. This can happen with new releases until reputation is established.

## Updates

PDF Lawyer checks this repository for new releases and can update itself automatically.

- Updates are downloaded in the background and applied on next restart.
- You can also update manually by downloading and running the newest installer. Your settings and data are preserved.

Release notes for every version are listed on the [Releases page](../../releases).

## System Requirements

- **OS:** Windows 10 or later (64-bit)
- **RAM:** 4 GB minimum
- **Disk space:** ~300 MB
- **Internet:** required for updates only
